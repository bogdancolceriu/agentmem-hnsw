\subsection{A check with a language model in the loop}
\label{sec:llm}

The agents above follow rules. To check that the differences between retrieval methods do not come from those rules, the \LlmDays{}-day scenario was repeated with a local language model (\code{\LlmModel{}}, run through Ollama) taking two decisions from the moment Maria learns about her party. In a conversation the speaker sees the pieces of news among its retrieved memories and the model chooses which one to mention, if any. When planning, the agent sees every memory it retrieved and the model lists the events it will attend that day. An event counts only if it matches news that the agent actually retrieved. The days before the announcement are simulated with the rules, and the three retrieval policies run as exact scans, so that only the policy differs. A run makes about \LlmCalls{} calls to the model. \Cref{tab:llm} compares the outcomes with those of the rule-based agents in the same \LlmSeeds{} worlds.

With the model in the loop, \LlmExAware{} agents know about the party under the full score, \LlmReAware{} under overfetch and \LlmRelAware{} under relevance only. With the rules the three figures are \LlmRuExAware{}, \LlmRuReAware{} and \LlmRuRelAware{}.
